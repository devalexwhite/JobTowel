# Interface conventions

The user chose conventional Bootstrap styling. Use Bootstrap 5.3 variables and components, its system font stack, light surfaces, primary buttons, standard form labels, visible focus, and inline validation. The index is a single responsive column with the form first and newest comments below it. Do not add a custom brand or ornamental components to this foundation.

The comments panel covers empty, populated, posting, validation, and success states. Comments preserve line breaks, escape user input through Maud, and wrap long words. Server and network errors appear near the form without clearing draft text.
